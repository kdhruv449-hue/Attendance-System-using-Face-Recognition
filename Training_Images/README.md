# Training Images

Add clear face images to this folder to use the face recognition system.

## Example

Training_Images/
├── Aman.jpg
├── Rahul.jpg
└── Priya.jpg

The image filename is used as the person's name.

For example:

Dhruv.jpg → DHRUV
Aman.jpg → AMAN

### Tips

- Use a clear, front-facing photo.
- Keep one person per image.
- Make sure the face is clearly visible.
- Use `.jpg`, `.jpeg`, or `.png` images.
